# ATHI 360 LTD

We build software that gives people back things modern life wore away: shared stories, hands-on curiosity, home cooking, and the confidence to look after their own affairs.

This repository is our public record: where to get the latest version of each product, what changed, and the state of our services. The work itself lives in private repositories.
